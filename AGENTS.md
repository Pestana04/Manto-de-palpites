# Manto de Palpites

- A pedido do proprietário, conclua cada alteração deste projeto com validação apropriada, commit e push para o GitHub. Não use force push. Relate falhas de autenticação ou conflitos sem sobrescrever trabalho do usuário.
- A versão publicada no Sites está espelhada em `sites/`. Ao editar o checkout gerenciado do Sites, sincronize os arquivos-fonte correspondentes nesta pasta após a publicação. Não copie `.git`, dependências, builds, arquivos de ambiente, credenciais ou bancos de dados.
- O projeto Java original permanece na raiz. Preserve alterações pessoais do IntelliJ e não inclua mudanças alheias ao trabalho no commit.
- Nunca versionar chaves da API, dados de participantes, fotos enviadas por participantes ou backups de produção.
